# آقای موبایل — نسخه رایگان بدون R2

این نسخه برای Cloudflare Workers + D1 ساخته شده و برای راه‌اندازی به R2 یا کارت بانکی نیاز ندارد.

## امکانات
- فروشگاه عمومی
- پنل مدیریت در `/admin`
- افزودن، ویرایش و حذف محصول
- ذخیره محصولات در Cloudflare D1
- نمایش عکس محصول با لینک مستقیم تصویر
- احراز هویت با Secretهای Cloudflare
- Deploy از GitHub

## راه‌اندازی
1. D1 با نام `mr-mobile-products` بساز.
2. جدول `products` را با SQL/migration پروژه بساز.
3. `database_id` در `wrangler.json` تنظیم شده است.
4. در Cloudflare دو Secret بساز:
   - `ADMIN_PASSWORD`
   - `ADMIN_SECRET`
5. Deploy کن.
6. سایت: `/`
7. پنل: `/admin`

## عکس محصولات
در این نسخه R2 حذف شده است. داخل پنل برای هر محصول «لینک مستقیم عکس» وارد می‌کنی.
بعداً اگر R2 را فعال کردی، می‌توانیم آپلود مستقیم عکس را اضافه کنیم.

Secretها را داخل GitHub commit نکن.
